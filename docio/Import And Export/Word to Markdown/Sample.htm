This sample demonstrates how to convert the Word document to Markdown using .NET Word (DocIO) library.

Below is the illustration of the output document.

Features :

  • Supports to convert existing Word document or created using .NET Word (DocIO) library to Markdown.
  • Supports to convert headings, tables, hyperlinks, list, and images from Word document to Markdown.
  • Supports to customize the image path while exporting as Markdown.
