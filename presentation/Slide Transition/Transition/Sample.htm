Essential Presentation library has support for creating slide transitions in a PowerPoint presentation.

This sample demonstrates how to add different transition effect for slides.

Features:

The below transition effects are supported as equivalent to Microsoft PowerPoint:

  • Subtle
  • Exciting
  • Dynamic Content

The below transition options are supported as equivalent to Microsoft PowerPoint:

  • Effect options
  • Advance On Time
  • Advance Mouse On Click
  • Transition Duration
