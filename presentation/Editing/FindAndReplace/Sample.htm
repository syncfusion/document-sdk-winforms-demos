This sample demonstrates how to replace a specific text or text pattern in the PowerPoint presentation with another text using Find and Replace functionality of .NET PowerPoint library.

Features :

  • Supports to find and replace the text or text pattern with another text in all PowerPoint slides and elements such as Shape, Textbox, Table, SmartArt, etc.
  • Supports to replace the text in specific slide, notes slide, master slide or layout slide.
  • Supports to replace the text by matching case, whole word and all occurrence or first occurrence alone.
  • Supports to replace the content that spans across several lines.
