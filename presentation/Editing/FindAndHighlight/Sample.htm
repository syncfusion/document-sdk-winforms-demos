This sample demonstrates how to find a specific text and highlight it in an existing PowerPoint presentation using Find functionality of .NET PowerPoint library.

Features :

  • Supports to find the first occurrence or all the occurrences of the text in the PowerPoint presentation.
  • Supports to find the text from specific slide, notes slide, master slide or layout slide.
  • Supports to find the text by matching case, whole word and all occurrence or first occurrence alone.
  • Supports to find the content that spans across several lines.
