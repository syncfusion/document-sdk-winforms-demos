This sample demonstrates how to convert the PowerPoint presentation to Markdown using .NET PowerPoint (Presentation) and .NET Markdown libraries.

Below is the illustration of the output document.

Features :

  • You can convert existing PPTX documents or those created using the .NET PowerPoint (Presentation) library to Markdown.
  • You can convert text, tables, hyperlinks, list, and images from PPTX documents to Markdown.
  • You can customize the image path while exporting to Markdown.
